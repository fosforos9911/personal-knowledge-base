# 设计决策记录

这份记录用于替代不可复现的“思考过程”，只保留可以审阅、修改和回溯的设计依据。

## 2026-08-31：建立独立工程

工作区原有 `MM-Agent` 工程并非空目录，且与本个人知识库目标不一致。因此新建独立目录 `personal-knowledge-base`，不修改旧工程。

## 2026-08-31：范围收敛为单用户

使用者明确本轮只需要个人学习和 FDE 工作辅助，不纳入企业部署、多用户、社区交流、联网搜索或 GitHub 集成。这样可以优先完成文档到问答的核心闭环，减少账号、权限、外部连接和运维复杂度。

## 2026-08-31：文档字段精简

保留会影响检索和学习的字段：标题、类型、行业、作者、时间、语言、可信等级、地区、项目阶段、关键词、产品、版本和复核时间。删除版权状态和原始文件等个人使用场景下不需要作为业务字段管理的内容。

## 2026-08-31：SQLite 起步

单用户应用优先使用 SQLite + FTS5，减少部署和维护成本；通过仓储和检索接口预留迁移到 PostgreSQL/pgvector 的能力。500GB 约束主要由文件目录承载，不能把原始 PDF 直接存入数据库。

## 2026-08-31：知识图谱后置

图谱价值依赖稳定的实体类型、关系类型和文档引用。先实现可定位原文的文档和检索闭环，再从实际资料中提炼图谱模型，避免一开始生成大量无法校验的关系。

## 2026-08-31：回答必须带证据

FDE 场景需要能够回看方案依据。AI 服务必须接收检索上下文并输出引用；无证据时返回资料不足，而不是补全成确定结论。
